# Community defaults

GitHub reads this repository when another repository of mine does not carry its
own copy of these files, so every tool gets the same issue templates, security
policy and contribution guide without twenty duplicates drifting apart.

| File | What it is |
| --- | --- |
| [`SECURITY.md`](.github/SECURITY.md) | How to report something that lets data escape, and what counts |
| [`CONTRIBUTING.md`](.github/CONTRIBUTING.md) | How to run the tests, and what a change needs to carry |
| [`ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) | Bug report, feature request, and where to write about work |
| [`PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | Three questions a reviewer would ask anyway |

The tools themselves are at [github.com/dkautomation23](https://github.com/dkautomation23)
and described at [dkautomation23.github.io](https://dkautomation23.github.io).
